# Cybersecurity Writeups

This repository is where I document my progress in cybersecurity through hands-on labs and CTF challenges.

I'm currently learning cybersecurity and using practical exercises to improve my technical skills and understand how different security concepts work in real situations. I created this repository to keep track of what I learn, the tools I use, and the challenges I work through.

## What's Inside

* **Phishing Analysis:** Investigating suspicious emails, email headers, and attachments.
* **CTF Challenges:** Documenting the steps I take to solve challenges and understand the techniques involved.
* **Network Security:** Learning about ports, services, and network scanning.
* **Linux:** Practising commands, permissions, and basic system administration.
* **Security Tools:** Notes and practical examples from tools I use during my labs.
